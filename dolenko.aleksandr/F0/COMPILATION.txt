🏗️ АРХИТЕКТУРА:

Основные компоненты:
  1. UniversitySystem - главный контроллер системы
     └─ Управляет институтами, аудиториями, бронированиями

  2. ScheduleAVL<T> - AVL-дерево расписания
     └─ Глобальное хранилище всех бронирований
     └─ Предотвращает конфликты времени
     └─ Обеспечивает логарифмический поиск

  3. BiList<T> - двусвязный список
     └─ Хранит институты и комнаты
     └─ Безопасная итерация в обе стороны

  4. CommandParser - интерфейс командной строки
     └─ Полное разделение логики и I/O
     └─ Парсинг пользовательских команд

✨ КЛЮЧЕВЫЕ ОСОБЕННОСТИ:

1. Авто-инициализация при старте
   └─ Не нужно вручную добавлять институты и комнаты

2. Глобальное обнаружение конфликтов
   └─ Единое AVL-дерево для всех бронирований
   └─ Невозможно забронировать одну комнату дважды

3. Чистая архитектура
   └─ Полное разделение бизнес-логики и интерфейса
   └─ Легко модифицировать или тестировать

4. Производительность
   └─ O(log n) вставка, удаление, поиск в расписании
   └─ O(n) поиск по коллекции (институты/комнаты)

5. Отсутствие зависимостей
   └─ Только C++ 17 стандартная библиотека
   └─ Никаких внешних зависимостей
