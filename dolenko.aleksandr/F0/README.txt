ДОСТУПНЫЕ КОМАНДЫ
═════════════════

add_institute <name> / добавить_институт <name>
  Добавить новый институт
  Пример: добавить_институт "ФТФ"

add_room <number> / добавить_аудиторию <number>
  Добавить новую аудиторию
  Пример: добавить_аудиторию 403

assign_room <room_number> <institute_name> / назначить_аудиторию <room_number> <institute_name>
  Назначить аудиторию институту
  Пример: назначить_аудиторию 403 ФТФ

book_room <institute> <room> <date> <time> <duration> / забронировать_аудиторию <institute> <room> <date> <time> <duration>
  Забронировать аудиторию
  Дата формат: YYYY-MM-DD
  Время формат: HH:MM (24-часовой формат)
  Длительность: в минутах
  Пример: забронировать_аудиторию ГИ 101 2025-09-21 10:00 90

cancel_booking <booking_id> / отменить_бронь <booking_id>
  Отменить бронирование по ID
  Пример: отменить_бронь 1

find_booking <booking_id> / найти_бронь <booking_id>
  Найти детали бронирования по ID
  Пример: найти_бронь 1

show_schedule <type> <name> <date> / показать_расписание <type> <name> <date>
  Показать расписание
  Тип: "room" (комната) или "institute" (институт)
  Дата формат: YYYY-MM-DD
  Пример: показать_расписание room 101 2025-09-21
           показать_расписание institute ГИ 2025-09-21

free_rooms <institute> <date> <time> <duration> / свободные_аудитории <institute> <date> <time> <duration>
  Найти свободные аудитории для института в указанное время
  Пример: свободные_аудитории ГИ 2025-09-21 14:00 90

clear / очистить
  Очистить все данные (не очищает исходные данные)

help / помощь
  Показать справку по командам

exit / выход
  Выход из программы

ОСОБЕННОСТИ РЕАЛИЗАЦИИ
══════════════════════

✓ AVL-дерево для глобального расписания (защита от конфликтов)
✓ Автоматическое предотвращение двойного бронирования
✓ Защита памяти: std::unique_ptr вместо raw pointers
✓ Идиома copy-and-swap для сильной гарантии исключений
✓ Двусвязный список (BiList) для всех коллекций
✓ Чистое разделение логики (UniversitySystem) и I/O (CommandParser)
✓ Полная const-correctness
✓ Безопасные итераторы для обхода данных
✓ Нет Makefile - компилируется прямой командой clang++

ФАЙЛЫ ПРОЕКТА
═════════════

Основные файлы:
  • main.cpp - главная программа с командным интерфейсом
  • UniversitySystem.hpp/cpp - система управления расписанием
  • credentials.hpp/cpp - информация о разработчике

Структуры данных:
  • Booking.hpp - структура для бронирования
  • Institute.hpp - класс института
  • Room.hpp - класс аудитории
  • ScheduleAVL.hpp - AVL-дерево расписания
  • AVLNode.hpp - узел AVL-дерева

Переиспользованные из S1:
  • BiList.hpp - двусвязный список
  • Node.hpp - узел связного списка
  • Iterators.hpp - итераторы

Вспомогательные:
  • build.sh - скрипт для компиляции и запуска
  • README.md - полная документация
  • README.txt - этот файл
